# Security

This is development version 0.1.0, a bounded in-memory concurrency lab. It is not an isolation boundary for untrusted workloads. The CLI accepts only fixed scenario options and does not execute supplied programs or load arbitrary files. Build scripts execute compilers and require the external isolated resource gate documented in the READMEs.

Report suspected vulnerabilities using GitHub private vulnerability reporting:

https://github.com/martinlofranodeoliveira/swift-actor-transition-rehearsal/security/advisories/new

Include a minimal synthetic reproducer, selected environment identity, observed result and whether cleanup was incomplete. Do not include credentials, real personal data or private client code. Do not post an unfixed vulnerability in a public issue. No response time, support term or certification is promised.

For non-security contact use the official homepage: https://lofranotecnologia.com.br .
